# 🌐 TechVision - Innovación Tecnológica

Proyecto web que presenta la página de **TechVision**, una empresa ficticia dedicada a soluciones tecnológicas de vanguardia. Esta maqueta incluye secciones de productos, servicios, noticias, contacto y footer corporativo, diseñada para demostrar maquetación profesional con **HTML y CSS**.

## 🚀 Descripción

TechVision es un sitio web corporativo que ofrece:

* Hero section con llamada a la acción
* Productos destacados en tarjetas con imágenes y descripción
* Sección de servicios con íconos representativos
* Sidebar con noticias recientes y formulario de contacto rápido
* Footer completo con enlaces, información de contacto y redes sociales

El diseño es **responsive** y utiliza fuentes modernas, iconografía Font Awesome y buenas prácticas de accesibilidad y SEO.

## 🛠️ Tecnologías utilizadas

* **HTML5** – Estructura y semántica del sitio
* **CSS3** – Estilos y diseño responsive
* **Normalize.css** – Normalización de estilos entre navegadores
* **Google Fonts** – Tipografía Inter y Poppins
* **Font Awesome** – Iconos y elementos visuales

## 📁 Estructura del proyecto

```bash
📦 TechVision
 ┣ 📜 index.html         # Página principal
 ┣ 📜 normalize.css      # Normalización de estilos
 ┣ 📜 styles.css         # Estilos personalizados
 ┗ 📁 images             # Imágenes utilizadas en la web
```

## 🎨 Funcionalidades

1. Navbar con menú responsive y botones de búsqueda y móvil.
2. Hero section con título, subtítulo y botones de acción.
3. Sección de productos en grid con tarjetas interactivas.
4. Servicios destacados con iconos y descripción.
5. Sidebar con noticias recientes y formulario de contacto rápido.
6. Footer con enlaces, información corporativa y redes sociales.
7. Diseño responsive adaptado a dispositivos móviles y escritorio.
